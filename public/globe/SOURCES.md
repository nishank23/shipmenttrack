# Globe land mask

`land-mask.png` is a 1024×512 black-and-white land/ocean mask derived from
"Blue Marble Next Generation + topography + bathymetry" by Reto Stöckli,
NASA Earth Observatory (modified by NordNordWest), public domain, via
Wikimedia Commons:
https://commons.wikimedia.org/wiki/File:Blue_Marble_Next_Generation_%2B_topography_%2B_bathymetry.jpg

Pixels whose colour is ocean blue became black; everything else (land, ice) white.
